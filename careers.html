Three roles, one team.

Each role lists the qualifications we look for, the skills you'll need and what a normal week involves.

Web Developer

Build and maintain client websites from design to launch.

Apply for this role

Qualifications

  • Level 3 qualification in web development
  • Level 2 IT user skills
  • Level 4 mathematics
  • A degree in web development

What you'll need

  • Knowledge of operating systems, hardware and software
  • The ability to write and debug code
  • Close attention to detail
  • Flexibility and openness to change

What you'll do

  • Turn design mock-ups and wireframes into working pages with HTML, CSS and JavaScript
  • Make sure sites work on every screen size
  • Build interactive features that improve the user experience
  • Test sites across browsers for consistent behaviour

IT Technician

Keep our team's computers, networks and devices running.

Apply for this role

Qualifications

  • A bachelor's degree
  • A level in Computing or IT
  • Level 3 Computer Science
  • Level 3 Systems Analysis

What you'll need

  • Strong problem-solving skills
  • The ability to diagnose faults and put fixes in place
  • Confidence gathering data to find the cause of a problem
  • Clear communication with non-technical colleagues

What you'll do

  • Answer support requests about systems, software and hardware
  • Diagnose and fix hardware and software issues
  • Set up and maintain computers, printers and mobile devices
  • Install and configure new hardware, servers and routers

Junior Web Developer

Start your career with mentoring from senior developers.

Apply for this role

Qualifications

  • Level 3 Computing and IT
  • Level 2 Certified Network Associate
  • Level 3 Cloud Computing
  • A bachelor's degree

What you'll need

  • Solid HTML and CSS for structuring and styling pages
  • Some experience with a framework such as React, Angular or Vue
  • A basic back-end language such as JavaScript (Node.js), Python, PHP or Java
  • Version control with Git and GitHub

What you'll do

  • Build web pages and features with HTML, CSS and JavaScript
  • Find and fix bugs, run tests and check browser support
  • Work with designers, senior developers and project managers to deliver on time
  • Help maintain and update existing websites
